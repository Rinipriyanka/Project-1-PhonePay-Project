# Project-1-PhonePay Pulse
The project aims to analyze and visualize aggregated values of payment categories, create maps for total values at state and district levels, and identify top-performing states, districts

## Technologies Used

Pandas
MySQL
StreamlitInteractive

### Nine Dataset Categories
1. **Aggregate Transaction** – Transaction counts by payment category.
2. **Aggregate User** – State-wise registered user information.
3. **Aggregate Merchant** – State-wise registered merchant information.
4. **Map Transaction** – District-wise transaction counts and amounts.
5. **Map User** – District-wise registered user information.
6. **Map Merchant** – District-wise registered merchant information.
7. **Top Transaction** – Transaction data for top geographical locations.
8. **Top User** – Registered user data for top geographical locations.
9. **Top Merchant** – Merchant data for top geographical locations.

The datasets are processed using Python and stored in a **MySQL database** for analysis

## Data Visualization Techniques
The project uses several visualization techniques:
- **Bar Charts:** Compare transaction counts and geographical performance.
- **Horizontal Bar Charts:** Display rankings of states and districts.
- **Pie Charts:** Show distributions across categories.
- **Doughnut Charts:** Visualize proportions and distributions.
- **Line Charts:** Analyze yearly and quarterly trends.
- **Stacked Bar Charts:** Compare payment categories across states.
- **Choropleth Map:** Visualize state-wise transaction amounts across India.
